## Which folder to open

GrillMyCode Companion works out which repository to read from the folder that is open, so it has to be the one you cloned from GitHub for this assignment.

- Open the assignment's folder itself, not a folder above it.
- A copy downloaded as a ZIP file won't work, because it isn't a clone.
- In a codespace, the right folder is already open.

If VS Code asks whether you trust the authors of the files in the folder, and the folder is your own assignment, choose to trust it. The extension relies on VS Code's Git support, which is switched off in Restricted Mode.
