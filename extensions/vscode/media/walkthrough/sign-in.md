## What the sign-in asks for

GrillMyCode Companion reads your questions through your GitHub account, using VS Code's own GitHub sign-in.

GitHub offers one permission for reading a private repository this way, which is access to your repositories, so that is what the sign-in asks for. The extension uses it only to read your questions. It changes nothing on GitHub and sends nothing anywhere else.

Sign in with the GitHub account that owns the assignment. If the GrillMyCode view says GitHub could not find the repository, you are signed in with a different account.
